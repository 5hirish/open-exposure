# Security policy

## Vulnerabilities found while testing products

OpenExposure does not hunt for vulnerabilities, but testing sometimes reveals them. When it
does:

1. Do not put the vulnerability in a report, issue, pull request or commit.
2. Email the editor privately (contact on the project site once live) with the details.
3. We report it privately to the developer and follow coordinated disclosure: publication
   only after a fix or after 90 days, whichever comes first.
4. A vulnerability is never used as leverage in the right-of-reply process.

## Vulnerabilities in this repository's tooling

Report them privately through GitHub's "Report a vulnerability" button on the Security tab.
